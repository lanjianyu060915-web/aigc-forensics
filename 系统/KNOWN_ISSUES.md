# 已知问题与边界

## AIGC 上游训练工程的可追溯边界

当前工作区没有完整的上游训练仓库、训练数据和可复现训练流水线。v0.4.0 正式包已经包含经核验的 AIGC 推理源码、Python 运行时和模型资源，并通过资源清单与 SHA-256 检查；这不是安装后推理的外部依赖。该限制影响的是重新训练和训练来源复核，不影响已验收模型的本地推理。

## 本次正式验收使用 CPU

本机硬件层面的 CUDA 可用，但随包 AIGC CUDA 后端不可用，InsightFace 运行时也未启用 CUDA provider。安装后四种真实任务均在 CPU 路径成功运行，页面会如实显示实际设备。GPU 路径本次没有通过正式推理验收；若要启用 GPU，必须另行准备并验证匹配的 CUDA、PyTorch/ONNX Runtime 和驱动组合，不能只修改 UI 标签或 `device` 字符串。

## 身份搜索是闭集候选排序

系统没有经过验证的开放集拒识阈值。库外人脸仍会返回相对 Top-K，应结合相似度和人工复核，不得把 Top-1 自动解释为身份确认。默认 45 张参考图中当前 43 张形成有效 embedding；两张因不满足单人脸要求被明确跳过，不影响其余缓存就绪状态。

**升级说明（M1，2026-09-20）**：检索器本身仍不做拒识，`open_set_rejection_enabled=false` 描述的这条边界依然成立；
但升级版在其上层新增 `decision/` 判定层，用独立校准集标定的阈值把库外查询判为「当前库中未发现可靠候选」，
把未检出人脸的查询判为「本次无法完成可比对检索」（后者不等价于「库中无此人」）。
身份判定使用 Top-1 人员均值余弦（拒识 0.2229 / 高可信 0.4698）与 Top1-Top2 间隔（最低 0.1874）。
阈值随检索算法与特征口径绑定，更换模型后必须重新标定。详见 `docs/M1_开放集三态与证据质量层.md`。

## 底图特征缓存（2.1）

旧版对 203 张图库每次都逐图提取特征，安装后单模块真实任务耗时 `112.0227` 秒。2.1 增加了库侧特征缓存：算法、权重和排序不变，只省去重复计算。首次建立缓存的耗时和旧版相近，之后只重算有变化的文件。缓存只在文件大小和修改时间都没变时才复用；OpenCV 版本变化时整体重建。比对工具见 `tools/verify_source_cache.py`。冻结 `source_search.exe` 保留在 `packaging_v0.3/work/dist/app/workers/source` 下，只用于比对，不参与运行。

## 正式包的资源自包含边界

v0.4.0 正式安装器包含已批准的三个模块运行时、模型和默认身份/底图库。正式入口不依赖开发机 A/B 环境、`D:\python`、Torch 用户缓存、已安装的旧 AIGC 系统或本项目开发目录；程序资源从安装目录解析，任务、报告、日志和缓存写入 `%LOCALAPPDATA%\FaceSourceTrace\`。安装后任务命令与日志中未发现开发目录或 `C:\Users\example\.cache\torch` 强制依赖。

该自包含范围不包括原始训练数据、完整训练流水线、互联网反向搜索服务或第三方联网数据源。离线合同已用空 `TORCH_HOME` 下的 AIGC portable、身份模块 `--offline`、正式资源本地化和前端无 CDN 合同验证；正式安装实跑没有触发下载。验收没有禁用操作系统网卡，因此不能表述为网卡级物理断网测试。

## 可视化证据的解释边界

AIGC 空间图是 Occlusion Sensitivity，表示遮挡区域对模型输出的敏感性，不是像素级伪造定位。AIGC 未配置专用五点关键点模型，相关页面只显示 OpenCV 实际检出的眼部候选中心；身份模块使用 InsightFace 的真实五点关键点。解释证据生成会增加 CPU 耗时和磁盘占用；可视化单独失败会降级展示，但不会修改权威检测分数。

## 输入与产品边界

界面接入单张 JPG/JPEG/PNG/WEBP（20 MiB 上限）、MP4/MOV/AVI/MKV 视频（200 MiB 上限）和批量图片（一次最多 100 张）。批量研判不支持视频。没有互联网反向搜索、案件管理、多用户队列或司法报告签名功能。任务按提交顺序串行执行，运行中的任务不能取消，只能等它结束。

## 安装路径长度（2.1）

Windows 默认路径上限 260 字符，本机也没有开启长路径支持。目录太深时，身份证据图会写不出来，分析结果本身不受影响。实测路径总长 260 字符时 5 张候选对比图写失败，259 字符时正常。所以要求系统所在目录不超过 60 字符；超过时启动窗口会警告，一键自检会判为未通过。系统不会替用户修改这项系统设置。

## 结果用途

三个模块的分数定义不同，不提供跨模块融合概率。AIGC 分数是本次输入的模型风险分数，不是模型准确率；身份和底图分数分别是当前库内候选相似度。系统结果仅用于风险筛查和侦查线索，应结合原始文件、传播链、设备信息和其他证据复核。
