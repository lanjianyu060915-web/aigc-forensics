# 修改日志

## 3.0 — 2026-11

### 人工比对闭环与补充证据 — 2026-11-05

- 人工复核增加类型倾向、依据素材候选快照和可选目标脸；复核版 PDF 明示人工判断，原机器结果和原报告不改写。
- 多人照片保留最大脸主结果，另列逐脸前三候选、原图框、缩略图及现有开放集判定。默认 CPU 六脸附加耗时超过三十秒，按性能约束将最终上限降为三张；视频仅首要帧追加。
- PDF 增加前三素材候选配对图、差异热图和逐脸表；TXT、HTML、PDF 及身份页展示逐脸身份候选。缩略图纳入证据清单，逐脸阈值尚未专门验证。
- 新增离线画面文字标识识别，文字命中与局限单独展示；失败和超时不影响其他模块，冲突提示不改变检测档位。初始词表与合成成绩不代表真实工具验证。
- 修复公开文档占位符检查、配对整体失败/跳过说明、报告路径脱敏和图片异常降级、复核摘要不一致提示及保存交互。
- 补充素材检索实际方法名的中文显示映射，覆盖字典与字符串输入；结构化方法、排序和分数保持原样。
- 补接实际身份研判页的逐脸候选区，置于主脸证据之前；单脸布局和主结果保持不变，单张脸失败独立显示。
- 实际来源页展示配对初始化失败、失败及部分完成的脱敏提示，跳过单独说明；保留其他模块候选和缺状态旧结果布局。
- 更新功能文档与文献使用边界；区分当前回归、旧版 PDF 验证和历史克隆记录，不将旧记录描述为当前远端同步。


### 素材配对与合并版本的历史变更

- 新增素材前三候选的人工配对对比：并排图、对齐滑动图、差异热图和逐脸数值；视频明确限定首要帧。当前不输出伪造类型，不绑定被修改人脸的身份。
- 新增案件库检查和建索引入口，记录本次库的名称、文件数、清单摘要及有效建库时间；允许外部库，拒绝越出库根的引用。
- 配对结果进入 JSON、文字报告、PDF 和证据清单，异常独立记录；原检测档位、检索排序和模型保持原样。

把换脸鉴伪系统和团队的视频检测项目合并成面向图片和视频的 AIGC 鉴伪与溯源系统。

- 新增通用 AIGC 分支：C38 + 3 个重训头 + CF384 融合，图片和视频都走，作为总体档位的主结论。
- 新增人脸分支：CF384 打人脸裁剪图。视频用抽帧时记录的人脸框，图片检测一次。最多把档位抬一级。
- 新增文件标识解析：GB 45438-2025 隐式标识、C2PA 容器结构、XMP DigitalSourceType、生成工具痕迹，有独立结果页。
- 总体档位规则重写：整图分支不再影响总体档位，只作提示。依据是它在普通真实视频上 63–81% 触发高风险。
- 整图分支改用作者的前处理（双线性、ImageNet 均值）并重新标定。SWAN-DF 全部 AUC 从 0.8969 升到 0.9506。
- 视频支持 WEBM。超过 90 秒的视频按时间点取帧，解码失败时转容错模式。
- 没有人脸时身份比对记为不适用，不再算失败。没有人脸的视频跳过逐帧检索，耗时从 145 秒降到 31 秒。
- 界面、报告和自检全部改成 AIGC 口径，“底图”改称“素材”。
- 运行环境改成脚本按锁定版本重建，权重和图库走 Git LFS，全部公开在仓库里。
- 修复：清单为空或条目缺少 SHA-256 时，证据完整性校验仍然提示全部一致。
- 图片、视频和换脸各做了一次盲测，结果在 `文档/测试报告.md`。

### PDF 研判报告和人工复核 — 2026-11-05

- 新增中文 A4 PDF 研判报告：结论首页、分支与证据强度表、视频逐帧图、人脸裁剪图、素材和身份候选、复核栏及版本和局限附录，每页带任务编号和页码。
- 新任务自动保存原版 PDF 并纳入证据清单；旧任务没有 PDF 时，点击导出在内存中生成，已有原版可直接下载。
- 新增人工复核表单，复核人和意见必填，结论可选“同意系统结论”“不同意”“无法判断”。记录附时间和原报告 SHA-256，只能追加保存，证据包收录复核记录。
- 有复核记录时现场生成复核版 PDF，不覆盖机器结果、原 JSON 报告或原版 PDF；明确说明手填姓名、记录时间和存证的局限。
- PDF 使用锁定版本的 ReportLab 和随程序分发的常规、粗体中文静态 TTF 字体。字体缺失或 PDF 生成失败只记录警告，TXT、HTML、JSON 报告仍正常生成。
- 图片从任务目录内的相对路径读取，缺图显示占位说明；用户文字和文件名先转义，支持含特殊符号的输入。

## 2.1 — 2026-11-03

以 9 月 21 日交付包（升级 2.0）为基线。模型、阈值、融合权重和排序公式都没有改。

- 补齐运行环境：交付包缺的身份模型、冻结鉴伪分支、Python 环境全部随目录提供，不再依赖开发机。
- 修复：命令行和常驻服务回退路径原来静默用一代模型，现在统一走二代内核（`modules/deepfake_detection_v2/run_deepfake_detection_v2.py`）。
- 提速：底图检索增加库侧特征缓存（`source_search/feature_cache.py`），与冻结 EXE 逐案例比对 23 例，最大分差 0。
- 修复：身份索引未建立时，身份和综合分析按钮被错误禁用。
- 修复：模型服务启动时整个页面卡住；现在后台启动，页面立即可用。
- 启动器：端口被占用时自动换端口；数据写到程序旁边的“用户数据”；不受本机其他 Python 环境影响；首次启动不再卡在 Streamlit 的邮箱提示。
- 新功能：批量研判、历史任务列表、证据完整性校验、证据包导出、输入预检（显示将走的鉴伪分支）、内置示例、研判要点和下一步建议、一键自检。
- 任务记录原始文件名；报告版本号显示 2.1。
- 界面重做：侧栏导航、分步操作、结论前置、状态中文化、上传控件中文化。
- 新策略：查询图有多张人脸时，原来报错，现在按面积最大选主脸比对，并在结果里记录人脸数和所选位置（`identity.multi_face_policy`，改回 `strict` 可恢复旧行为）。这会改变这类查询的结果。
- 修复：`.bat` 全部用 CRLF。原来只有 LF 换行，双击后 `chcp` 被读成 `cp`，批处理根本跑不起来。
- 修复：点“关闭系统”后，启动窗口不再误报“启动失败”。
- 修复：目录搬动后身份索引不再白白重建，指纹相同就直接复用（183 秒 → 6.8 秒）。身份模块预算从 180 秒放宽到 600 秒，慢机器首次建索引不再超时。
- 自检更严：新增安装路径长度和身份证据图两项。路径超过 60 字符时，启动窗口也会警告。此前路径过长会丢证据图，自检却仍显示通过。
- 预编译随包 Python 环境，依赖导入从 1.57 秒降到约 0.95 秒。
