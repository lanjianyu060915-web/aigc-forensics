# 第四版 · 工程改进版

本分支保存 AIGC 图像视频鉴伪与来源线索系统的第四版源代码。鉴伪、人脸相似候选、底图素材搜索、素材配对四项功能继续保留。版本号为 `0.4.0-v4-engineering`。

本版加强证据记录、结果一致性、失败恢复和运行可观测性。工程验证通过不代表模型准确率提高；当前没有足够证据启用实验策略。既有规则阈值、模型和默认选脸、采样方式保留。

## 主要入口

- `系统/start.ps1 -ConfigPath <配置绝对路径> -FrontendPythonPath <Python绝对路径>`：使用显式本机配置启动界面。
- `系统/tools/prepare_v4_profile.py`、`prepare_v4_inference_profile.py`：创建和审计隔离的独立验证配置。
- `系统/tools/run_v4_dev_batch.py`：执行通过准入门禁的固定开发清单；不会自动重跑中断推理。
- `系统/tools/run_v4_sampling_comparison.py`：按预先固定的内容组顺序进行同预算采样 A/B 对照，仅允许两项实验选帧开关不同，不自动选优部署。
- `系统/tools/run_v4_acceptance_batch.py`：执行已经冻结候选、配置、协议和输入全集的验收清单。
- `系统/tools/evaluate_v4_batch.py`：核验结构化结果，按固定内容组分母统计错误、覆盖、失败和置信上界。
- `系统/tools/recover_task_v4.py`：明确区分补收据、补报告、有限云端写作重试和新任务推理。原任务记录保留。

每个工具的实际参数以 `--help` 为准。独立执行须由本机可信启动环境提供当前排除政策路径；清单不能自行更换排除权威。门禁证明指定输入与指定政策的校验关系，不能代替来源真实性审查，也不能阻止外部程序绕过入口。

## 恢复运行环境

这是源代码备份，不含模型权重、Python 运行时、原始或派生测试资料、参考图库、人脸嵌入、运行缓存、私人配置、API 密钥及历史结果。字体程序及其许可单独包含。部署时需从自己的合规原安装中绑定模型、解释器、FFmpeg/ffprobe 和冻结阈值文件；依赖声明在各模块及 `系统/requirements`。

1. 将源代码恢复到新目录，保留原安装。
2. 建立独立数据及输出目录，明确查询与参考的角色。不要把旧任务目录作为新输出目录。
3. 使用本机配置绑定已获授权的模型和运行时，核对文件摘要与适用许可。私有配置及凭据留在备份之外。
4. 先运行下述合成工程检查，再使用独立、获准的固定输入验证。使用已有团队测试资料时必须保持其 test_only 属性和防自检索检查，不得用于选型、训练或校准。
5. 手动确认入口版本和输出目录后再打开实际数据。未通过效果条件时保留稳定版，仅交付工程改进版。

回滚只切换代码和配置入口；保留新旧任务记录，继续使用当时最新的训练排除政策，不回滚该政策。

## 验证与解释边界

新增工程测试使用程序构造像素、元数据、假模型或假 worker。应显式选择已审阅测试并加载 `-p v4_test_isolation`，不要直接运行可能引用历史资料的全库测试。真实编码测试需提供 `V4_TEST_FFMPEG` 与 `V4_TEST_FFPROBE`。准入测试需提供当前已校验检查器路径 `V4_TEST_EXCLUSION_CHECKER` 与摘要 `V4_TEST_CHECKER_SHA256`，只复制检查器到合成夹具，不加载真实数据。

人脸相似度只表示当前图中脸与库内条目的相似线索，不证明换脸、真人身份、制作人或被遮挡的原脸。素材相似度也不单独证明伪造。稀疏视频采样不覆盖每一时刻；时间可能来自帧号与帧率估算，不能等同解码 PTS。检测到、成功评分、参与图级定档和身份检索覆盖分别记录。

实验性的 selected_face、规则升档候选及分段采样必须通过独立影响验证后才可启用，当前默认关闭。云端写作只能组织既有结论；不允许修改已保存的最终风险档位。受限测试入口仅允许去标识结构化文字调用获准端点，独立验证入口禁用云端。
