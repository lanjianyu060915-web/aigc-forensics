# 换脸盲测集说明

人脸分支之前只在选模时看过的换脸数据上测过。这批数据是后来独立采集的，采集时没有运行任何检测模型，用来给人脸分支做一次带限制的补充盲测。图片本身不随仓库分发，这里保留清单和逐样本分数。

## 看成绩之前定下的规则

- **模型、公式和所有边界都不动。** 通用分支用图片边界，人脸分支用已有的人脸裁剪边界。
- **主结果用原始文件**（`manifest.jsonl`），因为系统实际收到的就是原始文件。
- **统一编码的副本只作对照**（`manifest_normalized.jsonl`），两个结果都报告，不按成绩挑选。
- **只跑一次。**

## 数量和来源

全部是 test，共 150 对真实和换脸图片：

| 来源 | 换脸方法 | 换脸 | 配对的真实图 |
| --- | --- | ---: | ---: |
| [OpenRL/DeepFakeFace](https://huggingface.co/datasets/OpenRL/DeepFakeFace) | InsightFace | 50 | 50 |
| [rshaojimmy/DGM4](https://huggingface.co/datasets/rshaojimmy/DGM4) | SimSwap | 50 | 50 |
| rshaojimmy/DGM4 | InfoSwap | 50 | 50 |

获取日期 2026-11-04，固定提交记录在清单里。排除了 SWAN-DF、DFDC、FaceForensics++ 和本机已有的换脸数据。

标签来自数据集的声明。DGM4 的数据卡声明 Apache-2.0，但底层新闻照片和供体图片的权利没有核实；DeepFakeFace 的数据卡许可声明前后冲突，按未核实处理。

## 捷径

只用宽、高、格式、文件大小的决策树：

| 输入 | 元数据 AUC |
| --- | ---: |
| 原始文件 | 0.689 |
| 统一成 512×512、JPEG q95 | 0.445 |

原始文件有一定可分性（主要靠图片高度），没有超过 0.75，但不能说没有捷径。

## 局限

- **人物身份分组不完整。** 只保证同一原图的真假配对不拆开，不能保证同一人物没有跨照片、跨来源重复。所以这是带限制的补充盲测，不是严格的人物独立盲测。
- 按 SHA-256 去重，查不出相似图；也不能证明模型训练时从未见过这些图片。
- 规模不大，每种方法只有 50 张，而且真假是配对的，不是相互独立的样本。
- DGM4 是新闻照片，DeepFakeFace 是名人人脸，和实战材料的分布不同。

## 文件

| 文件 | 内容 |
| --- | --- |
| `summary.json` | 汇总 |
| `scores.jsonl` | 逐样本分数 |
| `manifest.jsonl`、`manifest_normalized.jsonl` | 清单：来源、标签依据、SHA-256、配对分组 |
| `stats.json`、`metadata_baseline.json` | 元数据统计和捷径基线的完整结果 |
