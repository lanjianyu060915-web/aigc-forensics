# 换脸寻源系统 2.1 使用说明

## 启动

双击 `D:\换脸寻源_最新版\启动系统.bat`。

会弹出一个黑色窗口，程序就绪后浏览器自动打开系统页面。这个窗口要一直开着，关掉它系统就退出了。

- 不需要安装任何东西，也不需要联网，所有计算都在本机完成。
- 整个文件夹可以复制到别的电脑或别的盘，复制后照样双击启动。**放在短路径下**，比如 `D:\换脸寻源`，路径不要超过 60 个字符。路径太深时 Windows 写不出部分证据图，启动窗口和自检都会提示。
- 默认端口是 8767，被占用时会自动换一个，黑色窗口里会显示实际地址。

**演示前建议先双击 `运行自检.bat`。** 它用内置示例真实跑一遍三个模块，全部显示“通过”才说明系统可以正常演示。

## 退出

点页面左下角的“关闭系统”，或者直接关掉黑色窗口。

## 分析一张图片或一段视频

1. 左侧选“新建研判”。
2. 把文件拖进上传框，或点“选择文件”。图片最大 20 MiB（JPG、PNG、WEBP），视频最大 200 MiB（MP4、MOV、AVI、MKV）。没有素材时可以在下拉框里选一个内置示例。
3. 右侧会显示文件信息、SHA-256 和这张图将走的鉴伪分支，确认一下。
4. 点“一键综合分析”。也可以只跑其中一个模块。
5. 页面显示实时进度。完成后先看最上面的“研判要点”，再按需要查看五个页签。

做完一次后，点右上角“开始新的研判”回到上传页。

## 怎么读结果

系统分别回答三个问题，结果并列展示，**不合成总概率**。

| 问题 | 模块 | 看什么 |
| --- | --- | --- |
| 是否伪造 | AI换脸/深伪风险甄别 | 证据分带：高风险提示 / 需人工复核 / 证据不足 |
| 可能是谁 | 人脸身份搜索 | 四态结论：高可信候选 / 证据不足 / 当前库中未发现可靠候选 / 本次无法比对 |
| 原图在哪 | 原始底图搜索 | 同样的四态结论 |

几个容易读错的地方：

- **鉴伪分数不是概率。** 0.0137 也可能是“高风险提示”，因为分带边界来自定标集的真人图分布。看分带，不要看分数大小。
- **“证据不足”不等于真实。** 它只说明模型没有发现足够的风险信号。
- **“高可信候选”不等于确认。** 身份和底图都只在当前库内比较，库里没有的人或图不可能被找到。

## 批量研判

左侧选“批量研判”，一次选多张图片（最多 100 张，不支持视频），勾选模块后开始。系统逐张串行分析，结果汇总成一张表，可以导出 CSV（Excel 能直接打开）。某一张失败不影响其他图片。

每张图的完整证据都保存为独立任务，可以在“历史任务”里打开。

## 历史任务和证据固定

左侧选“历史任务”，可以看到所有做过的分析，选一个就能重新打开全部证据。

打开任务后页面下方有“证据固定”：

- **校验证据完整性**：按任务自带的清单重算每个证据文件的 SHA-256，能发现文件被改动或缺失。
- **生成证据包**：把任务目录打成 zip，附文件校验清单，便于移交和归档。

分析结果都保存在 `用户数据\runtime\tasks` 下，每个任务一个目录。

## 第一次使用为什么慢

身份库第一次要建索引（约 2～3 分钟），底图库第一次要建特征缓存，都只做一次。交付的目录里已经建好，搬动文件夹后也能直接复用，正常不会遇到。如果换了图库，可以在“系统状态”页点“建立 / 更新特征缓存”提前建好。

## 图片里有多张人脸

身份检索会选**面积最大**的那张脸比对，结果里写明检测到几张脸、选了哪一张。主脸不一定就是你想查的人，这种情况要人工确认。

## 使用其他身份库或底图库

在“新建研判”的“高级设置”里填目录路径：

- 身份库：一个目录，下面每个人一个子目录，子目录里放这个人的参考照片。
- 底图库：一个目录，里面放图片。

## 必须知道的边界

- 系统只提供侦查线索和辅助研判信息，不替代原始介质固定、哈希校验、人工复核或司法鉴定。
- 鉴伪分带在接近定标数据的输入上才可靠。复测中，案例 3 的 20 张原始照片有 15 张被判为高风险，说明换一批来源的图片时误报可能很高。
- 强压缩、大幅缩放、翻拍和二次编码都会让鉴伪结果变差。
- 视频级结论最弱：在 DFDC 真人视频上中/高风险误报达 53.3%，只能当线索。

## 遇到问题

| 现象 | 处理 |
| --- | --- |
| 黑色窗口一闪就没了 | 从命令行运行 `启动系统.bat` 看报错 |
| 页面左下方显示某模块“不可用” | 到“系统状态”页看具体缺什么；常见原因是文件夹没复制完整 |
| 模型服务一直“启动中” | 等 2 分钟；还不行就点“重新检测 / 重试服务”。常驻服务起不来时分析仍能进行，只是每次要重新加载模型 |
| 分析卡住 | 任务按顺序执行，运行中不能取消。视频和首次分析本来就慢，看进度条是否在走 |
