# 研判证据与线索规则

研判层从已有机器结果整理证据，不改变检测模型、原总体规则、身份开放集阈值或配对规则。原有伪造类型字段保持为空，自动类型结论保持关闭。新研判结果单独留痕，结论须经人工复核。

## 线索组合

| 编号 | 触发条件 | 使用边界 |
| --- | --- | --- |
| R1 | 高可信素材候选，且已有配对结果为 face_replaced | 仅支持建议人工复核，不能单独支持明显痕迹 |
| R1+ | R1成立，且同一张已绑定查询脸有高可信身份候选 | 候选不等于身份确认；必须明确人脸绑定 |
| R2 | 高可信素材候选，配对为 same_source_unchanged、face_edited_identity_kept 或 edited_elsewhere | 写明配对类型，不推断生成方式 |
| R3 | 文件声明为生成合成内容 | 声明可能伪造，未发现也不能排除生成 |
| R4 | 画面识别到生成相关字样 | 字样可能添加或裁切，须核查来源 |
| R5 | 通用分支低档，人脸分支中档或高档 | 两路作用不同，不能以通用低档否定人脸线索 |
| R6 | 检测总体高档，素材和身份均未发现高可信候选 | 库内未检出不等于没有来源 |
| R7 | 检测总体低档，标识、素材、身份均已完成且未发现线索 | 仅描述本次未发现，不能确认真实 |
| R8 | 任一模块失败、跳过或不适用 | 区分未知与未发现，不补造数据 |
| R9 | 已有配对结果为 same_background_other_person | 人物整体不同，不能按换脸线索处理 |
| R10 | 配对 inconclusive 或对齐失败 | 暂不能判断是否同源，保留失败原因 |

R1、R2、R9、R10只读取配对模块的已有判定；不从低身份相似度自行推导，也不使用身份库检索阈值替代成对规则。成对规则使用 `identity_different_max=0.55`、`identity_same_min=0.6`，并联合人脸尺寸、像素变化和人物周边稳定性；中间区间为灰区。身份库开放集规则只用于候选可信度。

历史任务如果只保存配对数值、没有保存配对类型，写明“未记录配对判定”，不得为命中R1重建或猜测类型。相关开发验证的可靠性应来自可核实的结果文件；缺失时标为未知。

R1+跨模块关联使用原图坐标框：仅当配对中发生变化的查询脸与身份模块恰有一张脸的交并比不低于0.8，且该脸已有开放集高可信判定时，才形成绑定。此几何关联门槛不替代人脸身份相似度门槛；多重匹配或坐标缺失保留未知。

配对历史可靠性固化于 `系统/reporting/reference_statistics.json`，每项附原汇总文件摘要。来源可核实的54组限定诊断：原图35/54，六种退化191/324，均未达到原要求。无害副本0/140、模拟美颜0/70、非配对难负误判同源2/451则来自原开发全量对照，不能说它们均来自54组子集。难负对照衡量错误同源关系，不等于AIGC真实样本误报率；同地点不同人尚未测试。此处沿用原实验，不重新消费留出媒体。

## 最终状态与约束

原总体低、中、高档依次映射为 `none`、`review`、`obvious`。原总体无档位或前置解码失败时为 `undetermined`，显示“无法完成判断”、评分为空，不运行研判调用。

出现文件生成声明、画面生成字样、主检测分支高档或R1时，模型输出不得低于review。只有通用或人脸分支高档、文件生成声明或画面生成字样允许obvious；R1不在此列。模型最多调整一档，调整必须引用实际存在的非图件证据。失败回退原规则档位，分数为空，并显式标记回退原因。

0–100分是可疑度评分，不是概率。档位中文名称从配置读取。图件只能辅助解释，不能单独形成上调依据。

## 统计、图件与上传

档位统计须绑定实际后端、最大脸或逐脸聚合口径与阈值版本；没有匹配统计时写“无对应统计”。总体档位统计不得冒充某个分支的统计。检测原始分数、阈值和版本分别保留。

图件按固定类型顺序编号F01起；原图、最高分人脸、第一素材候选的配对三联图、第一身份候选对照、命中文字区域以及分数示意图为存在时必放项。视频曲线仅在有帧级记录时生成，不从视频级分数补造。

上传视图先移除本机路径，再按范围整理。仅文本模式不上传任何图片，并将文件名、任务编号、哈希、人员和库名替换为本地可追溯的代号。材料原有文字采用固定材料内容包装，不能作为指令。PDF可在本地嵌入原始图件，不受云端缩略图上传范围影响。
