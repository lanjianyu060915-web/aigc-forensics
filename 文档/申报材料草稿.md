## 成果简介

三个检测分支，其中两路定结论，一路只作提示。

生成式 AI 让伪造图片和视频的门槛大幅降低，办案人员面对可疑材料，既要判断是否生成或换脸，也要查清来源，而现有检测工具换一批来源就容易失效，且需要上传材料。本成果是一个离线运行的桌面系统：上传图片或视频后，用通用检测、人脸裁剪检测、整图检测三路模型给出“证据不足、需人工复核、高风险提示”三档结论，同时从文件标识（GB 45438-2025、C2PA）、原始素材检索、人脸身份比对三层给出来源线索，并生成带 SHA-256 校验的报告和证据包。模型冻结后的盲测中，图片 AUC 0.886，视频 AUC 0.922。

## 设计、开发、制作的目的和基本思路

**目的。** 给办案人员一个能在本机离线运行的研判工具，回答三个问题：是不是 AI 生成或换脸，从哪里来，判断能不能复核和留痕。结果作为侦查线索和辅助研判信息，不替代人工复核和司法鉴定。

**基本思路。**

1. 单个检测器跨来源不稳定，所以用多路检测，分别标定，只由档位推导结论，不把分数合成一个概率。
2. 只判真假不够办案用，所以把文件标识解析、素材检索和身份比对放进同一个流程。
3. 边界不凭经验定，用真实样本分数的 p95、p99 确定，含义是“这个分数在真实样本里有多少见”。
4. 效果用盲测说话：采集评测集时不看模型分数，模型定稿后只跑一次，并如实报告捷径和局限。

## 创新性、先进性、实用性的体现及使用说明，技术特点和优势

**创新性**

- **分档而不是概率。** 用真实样本分位点分档，总体结论由确定性规则从各路档位推导。实测跨数据集加权融合时，外部集 AUC 从 0.898 掉到 0.439，这个做法避开了这个问题。
- **检测和溯源一体化。** 同一次分析同时得到检测档位、文件标识、原始素材和身份候选，换脸时可以把原图和查询图并排对比。
- **国标隐式标识解析。** 按 GB 45438-2025 解析图片和视频元数据里的生成标识，不依赖模型，命中时是很强的线索。
- **按实测决定每路模型的作用。** 例如发现整图分支在普通真实视频上 63–81% 误报高风险后，把它改为只作提示；发现视频模型的原检测头在图片上失效后，图片改用重训头和 CF384 融合。

**先进性（盲测数据）**

| 测试 | AUC | 真实样本误报 | 生成样本检出 |
| --- | ---: | ---: | ---: |
| 图片（1200 张，10 个生成器家族） | 0.886 | 7.8% | 65.7% |
| 图片传播退化（800 张） | 0.812 | 9.2% | 55.8% |
| 视频（146 条，8 个生成器家族） | 0.922 | 15.9% | 76.6% |
| 视频统一转码后（120 条） | 0.917 | 10.0% | 71.7% |
| 换脸图片（300 张，3 种方法，补充盲测） | 人脸分支 0.663 | 14.0% | 36.0% |

覆盖 Sora、Veo、Runway、Seedance、GPT-Image、Midjourney、FLUX、Seedream 等较新的生成器。误报和检出指进入“需人工复核”及以上的比例。

**实用性**

- 全程离线，数据不出本机，适合处理涉案材料。
- 自动固化文件并记录 SHA-256，证据包可移交，事后可重新校验。
- 自动生成可打印的中文 PDF 研判报告；人工复核意见单独追加保存，导出复核版保留原版，复核记录随证据包移交。
- 有开放集判定，库里没有时会明确说未发现可靠候选，不会硬给一个结果。
- 支持批量筛查，一次最多 100 张图片，结果可导出表格。

**使用说明。** 双击启动，拖入图片或视频，点“一键综合分析”。图片约 1 分钟，没有人脸的短视频约 30 秒，有人脸的视频约 2–3 分钟。先看研判总览，再按需查看各页证据，最后导出报告或证据包。

报告区域可下载 PDF，也可填写复核人、结论和意见，追加保存后导出复核版。旧任务没有 PDF 时会现场生成；PDF 不可用时仍可使用 TXT、HTML 和 JSON 报告。复核人姓名是手填的，没有账号认证；这不是可信时间戳，也不是不可篡改存证。

**局限（要主动说明）。** 换脸检测弱，补充盲测上人脸分支 AUC 只有 0.663，大约三分之二的换脸图进不了复核，“证据不足”不能排除换脸；部分生成器漏检明显；边界换来源会漂移。所以系统只提供线索，不下真假结论。

## 2 分钟问答准备

| 可能的问题 | 回答要点 |
| --- | --- |
| 准确率多少？ | 不用单个准确率。盲测图片 AUC 0.886，真实样本 7.8% 进入复核，生成样本 65.7% 进入复核。它是筛查线索，不是判决 |
| 为什么不给一个概率？ | 模型分数没有校准，换来源含义就变。跨数据集加权融合时外部集 AUC 从 0.898 掉到 0.439，所以只报档位，边界含义是真实样本里有多少见 |
| 换脸检测效果怎样？ | 这是最弱的一环。补充盲测（300 张）人脸分支 AUC 0.663，换脸图只有 36.0% 进入复核。所以系统靠素材检索和身份比对配合，比如查到原图后并排对比人脸以外的部分 |
| 盲测可信吗？ | 采集时不看模型分数，模型定稿后只跑一次。图片集统一处理后元数据基线 0.513；视频集有捷径（0.960），所以同时报告转码后的 0.917 |
| 模型是自己训练的吗？ | C38 微调和重训检测头是团队训练的；CommunityForensics、InsightFace 是公开模型，融合公式、分档边界、人脸分支和总体规则是我们做的 |
| 遇到新的生成器怎么办？ | 可能漏检，比如 flux.2-klein-9b 只有 17.5% 进入复核。所以要持续更新评测集，并结合文件标识和溯源 |
| 标识被去掉怎么办？ | 标识只是线索，转码和截图都会丢。没有标识不说明任何事，还要看检测和溯源 |
| 能用作证据吗？ | 不能替代司法鉴定。它提供线索和可校验的留痕，帮办案人员决定往哪查 |
| 和在线检测工具比有什么不同？ | 离线，材料不外传；不只判真假，还给来源线索；结果可校验 |

## 素材配对与案件库升级

当前版本增加前三候选的人工配对对比和案件库检查建索引。展示并排图、对齐滑动图、差异热图及逐脸数值，报告保留库名称、文件数、清单摘要和建库时间；视频只代表首要帧。配对实验未达到启用自动结论的条件，因此不输出伪造类型，不将最大脸身份候选绑定为被修改人脸。原检测档位和素材排序不变。

离线实验完整保留开发集运行记录。来源审计发现其中一类数据只按同名文件建立配对，缺少真实底图映射，因此全量原始统计不能作为有效召回率。仅对来源可核实的开发子集作限定诊断，原图支持换脸为 35/54，退化图为 191/324，仍低于预设门槛；同背景不同人的团队数据也尚未到位。未消耗留出集，未调整标准来改判通过。SSCD 旧 N 诊断在既有可核实开发子集及原退化变换所覆盖的范围内，没有显示素材前三候选找回增益，尚不满足产品接入前提；该结果不覆盖所有困难场景，本段不包含新增难例测试的结果。后续盲测需先独立采集、冻结数据和版本，再按一次性协议执行。


## 人工复核、逐脸候选和画面标识

- 人工复核可记录类型倾向、依据的素材候选和目标脸，保存候选快照并绑定原报告摘要。复核版 PDF 明示“人工判断，非系统结论”；机器伪造类型仍为空，自动类型结论仍关闭。
- 身份比对保留最大脸的主结果，并为其他脸追加前三候选、原图位置、缩略图和现有开放集判定，包括主脸最多 3 张。每脸独立容错；单脸不重复检索；视频只在首要帧追加逐脸结果。系统不判断哪张脸被改动，逐脸阈值尚未专门验证。
- 文件标识页分别展示元数据声明和离线 OCR 识别到的画面文字。文字线索不改变检测档位；字样可以被添加、裁掉或压缩到无法识别，没识别到不代表不是生成内容，也不核验来源。初始词表尚未在真实工具输出上完整验证，合成字样测试不能当作真实工具识别成绩。

PDF 增加前三候选的配对图、差异热图及逐脸表。对齐失败时暂不能判断是否同源；热图只提示像素变化位置，几何对应不等于身份绑定。逐脸缩略图和结构化结果纳入证据清单。
